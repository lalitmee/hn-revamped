# Release 0.1.0 — HN Revamped

**Release Date:** 2026-10-22  
**Target Domain:** `https://hn-revamped.vercel.app`

Initial production release of **HN Revamped**, a fast, Google Material-inspired modern web client for Hacker News built with Next.js 15, React 19, and Tailwind CSS.

---

## What's New

### 1. Adaptive Workspace (Dual-Mode & Zen Focus)

- **Split-Pane Layout:** Continuous story browsing on the left with instant preview of comments and readable articles on the right.
- **Zen Mode:** Distraction-free single-pane view focused entirely on thread discussion or article reading.
- **Deep Linking:** Synchronized `?story=<id>` URLs enabling shareable story states, browser history navigation, and back/forward stack integration.

### 2. 11 E-Reader & Code Themes

- Comprehensive color palettes crafted for readability across ambient lighting environments:
  - **E-Reader:** Warm Paper, Kindle Sepia, Kobo Matte, Crisp Day.
  - **Developer:** Obsidian Slate, Catppuccin Mocha, Solarized Dark, Solarized Light, Nord Frost, Gruvbox Dark, OLED Midnight.
- Native CSS variable theming persisted in `localStorage`.

### 3. Unified Real-Time HN Data Engine

- **Direct Client Fetching:** Story feeds (Top, New, Best, Ask, Show, Launch, Jobs) streamed directly from the official Hacker News Firebase API.
- **Algolia Integration:** Single-request nested comment trees, instant search (`⌘K`), and front-page Time Travel presets (All-Time, 2024, 2023, 2020, 2015, 2010).

### 4. Distraction-Free Article Reader Mode

- In-app article extraction powered by `@mozilla/readability` and `linkedom`.
- Strict HTML sanitization via `dompurify` without heavy native dependencies.
- Rich fallback cards for non-article media (YouTube videos, GitHub repositories, direct PDF files).

### 5. Paragraph-Synced Audio Reader (Web Speech TTS)

- Integrated voice reader utilizing native browser `window.speechSynthesis`.
- Code-aware speech extraction that intelligently skips `<pre>` syntax and raw URLs.
- Paragraph stepper capsule with live text highlighting, playback speed adjustment (1x to 2x), and OS voice selection.

### 6. Comments, Bookmarks & History

- Multi-tier color-coded comment depth indents.
- Collapsible comment threads with preference persistence.
- Visited story tracking and client-side bookmark management.
- Vim-style keyboard shortcuts (`j`/`k`, `o`, `c`, `r`, `b`, `?`).

### 7. Open Source & Agent Operations

- Formally released under the permissive MIT License.
- Full operating rules and verification workflow documented in `AGENTS.md`.

---

## Infrastructure & Edge Optimizations

- **Edge CDN Caching:** `/api/reader` configured with `Cache-Control: public, s-maxage=86400, stale-while-revalidate=604800` on Vercel's Edge Network, eliminating duplicate serverless execution costs.
- **Client Cache:** Browser `sessionStorage` caching avoids re-requesting parsed articles when toggling tabs.
- **Crawler Guard:** `public/robots.txt` disallows `/api/` crawling to prevent search bot abuse.
- **Compute Ceiling:** Enforced 10-second serverless execution ceiling (`maxDuration = 10`) adhering to Vercel Hobby limits.
